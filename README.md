# Credit Risk Scoring Model

This project uses customer lending data to build a simple credit risk scoring model. The aim is to classify loan applicants into low, medium, or high risk based on features such as loan amount, credit history, employment status, and repayment risk.

## Project Objectives

- Clean and explore a credit risk dataset
- Identify factors linked to higher default risk
- Build a basic machine learning model to predict credit risk
- Evaluate the model using accuracy, precision, recall and a confusion matrix
- Explain the results in a clear business/risk-focused summary

## Tools Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook
